Dijkstra con priority_queue Modelo IA · v4

Explícame cómo implementar Dijkstra usando priority_queue en C++ y dame referencias para citar en mi entrega.

Claro. La idea es mantener un montículo mínimo con las distancias tentativas (Smith, J., 2021) y extraer siempre el nodo más cercano (Dijkstra, 1959). Cada relajación de arista puede empujar una entrada nueva al montículo, de modo que el coste total queda en O((V + E) log V) (Cormen et al.).

dijkstra.cpp#include <queue>
#include <vector>

using P = std::pair<int, int>;

void dijkstra(int src) {
  std::priority_queue<P, std::vector<P>, std::greater<P>> pq;
  pq.push({0, src});
  while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d > dist[u]) continue; // entrada obsoleta
    for (auto [v, w] : adj[u])
      if (dist[u] + w < dist[v]) {
        dist[v] = dist[u] + w;
        pq.push({dist[v], v});
      }
  }
}
